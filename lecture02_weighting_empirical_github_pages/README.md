# Xの分布と線形射影 — 第2回講義

`lecture02_weighting_empirical` 第2節の仮想例を，WebRで操作できる静的Webページにしたものです。平均曲線を両集団に共通にしたまま，補習時間Xの分布を変え，母集団の線形射影と標本OLSを比較します。

## GitHub Pagesで公開する

1. ZIPを展開します。
2. 公開先のGitHubリポジトリの直下に，展開したフォルダーの**中身**を配置します。`index.html` がリポジトリ直下にある状態にします。`.nojekyll` も含めてください。
3. ファイルを公開用ブランチ（例：`main`）へコミットします。
4. リポジトリの **Settings → Pages → Build and deployment** で，Sourceを **Deploy from a branch** にします。
5. ファイルを置いたブランチと **/(root)** を選び，**Save** を押します。
6. デプロイ完了後，Pagesの設定画面に表示される公開URLを開きます。

既存リポジトリの `/docs` を使う場合は，このフォルダーの中身を `/docs` に置き，手順5で **/docs** を選択します。別の教材のサブフォルダーに置く場合も，相対パスのまま動きます。公開元に指定できるフォルダーはリポジトリ直下または `/docs` です。

ビルド，npmでのパッケージ導入，Rサーバー，GitHub Actionsの独自ワークフローは不要です。計算に使うWebR 0.6.0は公式CDNから取得します。GitHub Pagesの通常の設定で動くよう，`ChannelType.PostMessage` を明示しています。

公開手順の出典：[GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。通信方式の出典：[WebR公式ドキュメント](https://docs.r-wasm.org/webr/latest/serving.html)。

## 操作

- 分布A・Bをそれぞれ変更すると，密度，散布図，母集団の係数，標本OLSを更新します。切断正規分布の平均と標準偏差は**切断前**の値です。散布図の横軸は0〜10時間，縦軸は条件付き期待値の範囲にその幅の半分の余白を加えて固定します。現在の平均関数では45〜105点となり，分布，標本サイズ，誤差の大きさ，シードを変えても平均曲線の位置は変わりません。表示範囲外の観測もOLSに含めます。
- 「標本を取り直す」はシードを2増やし，両集団の標本を生成し直します。分布と平均関数が同じなら，母集団の線形射影は同じです。
- 「観測を順に表示」では，同じ標本の先頭から観測を追加し，表示中の観測からOLSを更新します。「全観測へ」で標本全体へ戻ります。
- 凡例のチェック欄で，平均曲線，母集団の線形射影，標本OLSの表示を切り替えます。
- 近似誤差の図は `{m(x) − β₀ − β₁x}² f(x)` を表示します。表では，同じ分布のもとでA・Bの直線の損失を比較できます。
- 「繰り返し実験を実行」では，指定回数だけ標本を生成してOLSを推定します。分布や標本設定を変えると，前の繰り返し実験の結果を消します。
- CSVには表示中の観測と生成設定を保存します。Rコードには計算本体，設定，表示中の観測数，選択中の繰り返し回数を含めます。ダウンロードしたRコードは通常のRで単独実行できます。

## 初期設定と計算

平均関数は `m(x) = 60 + 6x − 0.3x²`，誤差はXと独立な `N(0, 5²)` です。Aは `N(2, 3²)`，Bは `N(8, 3²)` をそれぞれ `[0, 10]` に切断・再正規化します。各集団の標本サイズは300，シードは20261013です。

| 母集団の量 | 分布A | 分布B |
| --- | ---: | ---: |
| 切片 | 63.06205827 | 69.71796091 |
| 傾き | 3.665590264 | 2.334409736 |
| 6〜10時間の確率 | 0.1174983622 | 0.6656315449 |

これらは標本からの推定値ではなく，`model.R` を実行して数値積分から求めた値です。母集団の係数は `Cov(X,m(X))/Var(X)` と `E[m(X)] − β₁E[X]` で計算します。標本OLSは `lm()`，順次表示中のOLSは逐次更新した中心化積和で計算します。

標本生成は逆累積分布関数法です。Aは指定シード，Bは指定シード＋1，繰り返し実験は指定シード＋100，＋101を使います。設定変更時は各集団の基礎乱数を再利用します。繰り返し実験のOLSは `Cov(X,Y)/Var(X)` と同値な中心化積和から求めます。

画面の図はRが返した値をSVGで描画しています。乱数生成，係数，損失，繰り返し実験の計算はすべてWebRで実行します。外部のRパッケージは不要です。

## ローカルで表示する

Node.jsが利用できる環境では，このフォルダーで次を実行します。

```powershell
node serve.mjs
```

その後，ブラウザで `http://127.0.0.1:8766/` を開きます。Windowsでは `start.ps1` も利用できます。ポート番号を変える場合は `node serve.mjs 8767` とします。サーバーはこのPCのループバックアドレスだけで待ち受けます。停止はCtrl+Cです。

`index.html` のダブルクリックではなく，HTTP/HTTPSで開いてください。ローカル表示でもWebRの取得には通信が必要です。

## 計算を検証する

通常のRが利用できる環境で，このフォルダーから次を実行します。

```text
Rscript --vanilla tests/model_tests.R
```

資料の係数と確率，直線の平均関数，一様分布，母集団の直交条件，近似誤差の最小化，OLSの逐次更新，シードによる再現性を確認します。
