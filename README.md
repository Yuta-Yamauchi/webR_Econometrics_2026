# Xの分布と線形射影 — 操作説明

このページでは，補習時間 X と試験得点 Y の仮想データを生成します。2つの集団に共通する平均曲線 m(x) = E[Y | X = x] のもとで，X の分布を変え，母集団の線形射影と標本OLSを比較できます。

## ページを開く

画面右上に WebR の準備完了が表示され，散布図が現れるまで待ちます。初回の読み込みにはインターネット接続が必要です。

## 散布図と密度の見方

散布図の横軸は補習時間，縦軸は試験得点です。左に分布 A，右に分布 B から生成した標本を表示します。

| 表示 | 内容 |
| --- | --- |
| 青・茶色の点 | 1人ずつの仮想観測 |
| 緑の曲線 | 両集団に共通する条件付き期待値 m(x) |
| 青・茶色の実線 | 各集団の母集団の線形射影 |
| 黒の破線 | 表示中の観測から推定した標本OLS |

図の上のチェック欄で，曲線や直線の表示を切り替えられます。図の下には傾き，さらに下の表には切片・傾き・母集団の平均補習時間を表示します。

散布図の横軸は0〜10時間，縦軸は条件付き期待値の範囲を基準に45〜105点で固定しています。分布や標本を変更しても，平均曲線の表示位置は変わりません。縦軸の表示範囲外の観測もOLSの計算に含まれます。

散布図の下の密度の図は，補習時間の分布を表します。濃い塗りつぶしは6〜10時間の範囲で，この範囲に入る確率を図の上に表示します。

## 分布と標本の設定を変える

「実験の設定」を変更すると，散布図，密度，直線の係数を更新します。

| 設定 | 操作と意味 |
| --- | --- |
| 分布の形 | 集団ごとに，0〜10時間に切断した正規分布または一様分布を選びます。 |
| 切断前の平均 μ | 正規分布の位置を変えます。切断後の平均補習時間は，下の表で確認できます。 |
| 切断前の標準偏差 s | 正規分布の広がりを変えます。 |
| 平均曲線 m(x) | 曲線 60 + 6x − 0.3x² または直線 60 + 3x を選びます。両集団に共通です。 |
| 各集団の標本サイズ n | 1つの集団の観測数を20〜2,000人に設定します。 |
| 得点のばらつき σ | 同じ補習時間での得点のばらつきを0〜15で設定します。両集団に共通です。 |
| 乱数シード | 仮想データの生成に用いる値です。同じ設定とシードで同じ標本を再現できます。 |

「短時間」「中央」「長時間」を押すと，その集団を切断正規分布に切り替え，μ をそれぞれ2，5，8，s を3に設定します。

## 標本を取り直す・観測を順に表示する

| 操作 | 動作 |
| --- | --- |
| 標本を取り直す | シードを更新して，両集団の標本を生成し直します。 |
| 観測を順に表示 | 現在の標本を先頭から順に表示し，観測が増えるたびにOLSを更新します。 |
| 一時停止 | 観測の追加を止めます。「観測を順に表示」で再開できます。 |
| 表示する観測数 | スライダーで観測数を選び，その観測から推定したOLSを表示します。 |
| 全観測へ | 現在の標本全体を表示します。 |
| 初期値に戻す | 分布と共通の設定を初期値に戻します。 |

初期設定は，各集団300人，σ = 5，シード20261013です。分布 A は μ = 2，分布 B は μ = 8，どちらも s = 3 の切断正規分布です。平均曲線は m(x) = 60 + 6x − 0.3x² です。

## 繰り返し実験を行う

1. 分布，平均曲線，標本サイズ，得点のばらつきを設定します。
2. 「繰り返し回数」で200回，500回，1,000回，2,000回から選びます。
3. 「繰り返し実験を実行」を押します。

現在の設定で標本生成とOLSの推定を繰り返し，推定した傾きのヒストグラムを表示します。横軸は標本OLSの傾き，縦軸は度数です。縦線は各分布の母集団の傾きを示します。左右の目盛りは共通で，下の表には傾きの平均と標準偏差を表示します。

分布や標本の設定を変更すると，前の繰り返し実験の結果は消えます。新しい設定での結果を見るには，再度実行します。繰り返し回数を変えた場合も，実行ボタンを押して更新します。

## Rコードを保存する

「現在の設定のRコードを保存」を押すと，現在の設定，表示中の観測数，選択中の繰り返し回数を含むRコードを保存します。

モデルや計算方法は，ページ下部の「モデルと計算方法を見る」を開いて確認できます。
